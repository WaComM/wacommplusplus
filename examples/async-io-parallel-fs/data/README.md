# Input data staging

Place the six native WACOMM forcing files and `sources.json` of this experiment here, or set `io.base_path` explicitly, and record their provenance and checksums as described in the [example guide](../async-io-parallel-fs.md). Generated results belong in `output/` or the ignored repository `data/` run directory.
