# Versioned scientific product

WaComM++ releases comprise five inseparable layers: physics, implementation, tests, examples, and documentation. Release review covers all five. Any numerical or physical change is identified in release notes even when the public API is unchanged, and any changed example behavior is updated and validated in the same revision.
